מטרת התוכנית היא ליצור שעון מעורר דיגיטלי באמצעות Arduino. המערכת מציגה את השעה והתאריך על גבי מסך LCD, מאפשרת למשתמש לקבוע שעת התראה בעזרת לחצנים, ומפעילה באזר כאשר מגיע זמן ההתראה שנקבע.

בתחילת הקוד מיובאות הספריות הדרושות לפעולת המערכת. הספרייה Wire מאפשרת תקשורת עם מסך ה-LCD, הספרייה LiquidCrystal_I2C מאפשרת שליטה במסך, והספריות ThreeWire ו-RtcDS1302 מאפשרות תקשורת עם מודול השעון בזמן אמת (RTC).

לאחר מכן מוגדרים הרכיבים המחוברים לארדואינו. מוגדר אובייקט של מסך ה-LCD בגודל 16x2 תווים. בנוסף מוגדר מודול השעון DS1302 המחובר לפינים 3, 4 ו-5. בהמשך מוגדרים מספרי הפינים של שלושת הלחצנים ושל הבאזר.

המשתנים alarmHour ו-alarmMinute שומרים את שעת ההתראה שהמשתמש הגדיר. בתחילת התוכנית שעת ההתראה מוגדרת ל-07:00.

המשתנה alarmEnabled קובע האם ההתראה פעילה או כבויה. המשתנה alarmRinging מציין האם ההתראה מצלצלת כרגע. המשתנה showClock משמש למעבר בין מסך השעה והתאריך לבין מסך ההתראה. המשתנה mode קובע באיזה מצב המערכת נמצאת:
0 – מצב רגיל.
1 – הגדרת שעות ההתראה.
2 – הגדרת דקות ההתראה.

בפונקציה setup מתבצעת ההגדרה הראשונית של המערכת. הלחצנים מוגדרים כ-INPUT_PULLUP ולכן במצב רגיל הם נמצאים בערך HIGH וכאשר לוחצים עליהם מתקבל LOW. הבאזר מוגדר כרכיב פלט.

לאחר מכן מופעל מסך ה-LCD ומופעלת התאורה האחורית שלו. בהמשך מתחיל לפעול מודול השעון DS1302.

הפקודה:

RtcDateTime compiled = RtcDateTime(**DATE**, **TIME**);

לוקחת את התאריך והשעה של המחשב בזמן העלאת הקוד לארדואינו.

לאחר מכן הפקודה:

Rtc.SetDateTime(compiled);

מעדכנת את מודול השעון לערכים אלו.

הפקודה:

Rtc.SetIsRunning(true);

מוודאת שהשעון ממשיך לפעול ולספור זמן גם לאחר שהוגדרה השעה.

בפונקציה loop מתבצעת הפעולה המרכזית של התוכנית. בתחילת כל מחזור נקראת השעה הנוכחית ממודול ה-RTC ונשמרת במשתנה now.

לאחר מכן מופעלת הפונקציה buttons אשר בודקת האם אחד הלחצנים נלחץ ומבצעת את הפעולה המתאימה.

בהמשך הקוד נבדק האם השעה הנוכחית זהה לשעת ההתראה שהוגדרה. אם השעות והדקות שוות, המשתנה alarmRinging מקבל את הערך true וההתראה מתחילה לפעול.

כאשר alarmRinging שווה ל-true מופעל הבאזר באמצעות הפקודה:

tone(BUZZER, 1000);

הפקודה יוצרת צליל בתדר של 1000 הרץ. כאשר ההתראה אינה פעילה, הפקודה:

noTone(BUZZER);

מפסיקה את הצליל.

המערכת מחליפה באופן אוטומטי בין שני מסכים כל חמש שניות. המעבר מתבצע באמצעות הפונקציה millis אשר מודדת את הזמן שעבר מאז הפעלת הארדואינו. כאשר עוברות חמש שניות, הערך של showClock מתחלף וכך מוצג מסך אחר.

כאשר המערכת נמצאת במצב הגדרת שעה (mode = 1), מוצגת הכותרת SET HOUR ובשורה השנייה מוצגת שעת ההתראה שנבחרה.

כאשר המערכת נמצאת במצב הגדרת דקות (mode = 2), מוצגת הכותרת SET MINUTE ובשורה השנייה מוצגות דקות ההתראה.

במצב הרגיל מוצגת השעה הנוכחית בפורמט שעות, דקות ושניות. אם הערך קטן מ-10, הקוד מוסיף אפס בתחילת המספר כדי לשמור על תצוגה אחידה. לדוגמה, במקום 7:5:3 יוצג 07:05:03.

בשורה השנייה מוצגים היום, החודש והשנה.

כאשר מוצג מסך ההתראה, מוצג מצב ההתראה:
ACTIVE – ההתראה פעילה.
DISABLED – ההתראה כבויה.

בשורה השנייה מוצגת שעת ההתראה שנקבעה.

הפונקציה buttons אחראית לטיפול בכל הלחצנים. בתחילת הפונקציה נשמר המצב הקודם של כל לחצן באמצעות משתנים סטטיים. בצורה זו ניתן לזהות לחיצה בודדת ולא מספר לחיצות רצופות בזמן שהלחצן נשאר לחוץ.

כאשר ההתראה מצלצלת ולוחצים על לחצן SET, ההתראה נפסקת והמערכת מכבה את ההתראה.

כאשר לוחצים בו-זמנית על UP ועל DOWN, ההתראה מבוטלת לחלוטין והצלצול מופסק.

לחיצה על SET מעבירה בין מצבי העבודה השונים. המעבר מתבצע בסדר הבא:
מצב רגיל → הגדרת שעות → הגדרת דקות → חזרה למצב רגיל.

כאשר חוזרים למצב הרגיל, ההתראה מופעלת מחדש באופן אוטומטי.

במצב הגדרת שעות, לחיצה על UP מגדילה את שעת ההתראה בשעה אחת. כאשר מגיעים ל-23 ולוחצים שוב, הערך חוזר ל-0.

לחיצה על DOWN מקטינה את השעה. אם הערך יורד מתחת ל-0 הוא חוזר ל-23.

במצב הגדרת דקות, לחיצה על UP מגדילה את מספר הדקות. כאשר מגיעים ל-59 ולוחצים שוב, הערך חוזר ל-0.

לחיצה על DOWN מקטינה את מספר הדקות. אם הערך יורד מתחת ל-0 הוא חוזר ל-59.

לסיכום, התוכנית משלבת עבודה של מספר רכיבים יחד: מודול RTC למדידת זמן מדויקת, מסך LCD להצגת מידע, שלושה לחצנים לשליטת המשתמש ובאזר להתראה קולית. המערכת מאפשרת להציג את השעה והתאריך, לקבוע שעת התראה, להפעיל ולכבות את ההתראה, ולעבור בין מצבי עבודה שונים בצורה נוחה ופשוטה.
